## 原生IP、住宅IP、双ISP，三个词别混着用

这三个词经常被当成一回事，下单前值得花两分钟分清。

**原生IP**说的是注册地：IP的WHOIS国家与机房物理位置一致。洛杉矶机房的IP，注册国也是美国，这叫原生。一台放在洛杉矶的机器分到新加坡注册的IP，就不是原生。

**住宅IP／家宽IP**说的是归属：IP的ASN是Comcast、AT&T、中华电信这类民用宽带运营商，而不是Linode、Vultr这种IDC。平台风控查的就是这一层。

**双ISP**说的是注册记录：同一个IP在两个不同民用ISP名下都有注册，常见组合是美国Comcast + Charter、香港iCable + HGC。它的用处很具体：其中一个ISP的IP段被某个平台批量标记时，另一个段还能继续用。

这里有个全网内容最容易漏、也最容易被当成坑的点：**双ISP不等于给你两个IP**。丽萨主机全系套餐默认只给1个IPv4，要多IP得单独加购。所谓"双ISP"描述的是同一个IP的注册属性，不是数量。如果你冲着"两个IP"下单，收到货会发现只有1个。

适用边界也说清楚：只建站、跑爬虫、做科学上网中转，普通IDC VPS完全够用，没必要为家宽IP多花钱；做账号运营、跨境电商、解锁地区限制流媒体，家宽IP才是刚需，双ISP是加分项。
